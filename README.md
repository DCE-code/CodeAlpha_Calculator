# Calc — CodeAlpha Calculator

A responsive calculator built with semantic HTML5, CSS Grid and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication and division.
- Decimal input, percentage, sign toggle, clear and backspace.
- Keyboard support for digits and operators.
- Division-by-zero protection.
- Responsive layout for mobile, tablet and desktop.
- Light/dark theme preference saved with localStorage.
- Accessible labels and live display announcements.
- Avoids `eval()`; calculations use explicit arithmetic operations.

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.
